# Navigating RUC’s Campus Using AR
C# scripts used for the logic behind the RUC map using AR.
As part of a group project, we designed an Android application in Unity (version 2022.3.40f1) that employs AR to guide users/students around RUC. For routing, the application utilizes navigation technologies such as the A algorithm and polygon overlap avoidance. Each building on campus is designated as a destination with a specific entry point. The system also accounts for ongoing construction in 2025.
